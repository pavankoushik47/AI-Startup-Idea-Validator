## 📌 Executive Overview

Early-stage founders frequently generate promising startup concepts but struggle to evaluate market demand, addressable market sizing, competitive moats, execution pitfalls, and go-to-market viability. Traditional startup validation requires weeks of expensive, fragmented market research and consultant reports.

**Ventura AI** solves this by orchestrating an autonomous swarm of **8 specialized AI agents** that analyze an idea submitted in just 2-3 lines. The system retrieves live web signals, calculates TAM/SAM/SOM, discovers direct and indirect competitors, performs a 4-quadrant SWOT and risk audit, prioritizes an MVP using the MoSCoW framework, creates a 4-week "First 100 Customers" playbook, and compiles a presentation-ready executive PDF dossier with an interactive conversational advisor.

## 🧩 The 9 Specialized Modules

| # | Module / Agent | Role & Key Responsibilities |
|---|---|---|
| **1** | **Idea Intake & Workspace** | Accepts raw 2-3 line startup concept, domain hints, and geography; includes 1-click sample presets. |
| **2** | **Web Search Agent** | Formulates targeted market queries and retrieves live web results using Tavily API and DuckDuckGo fallback. |
| **3** | **Market Analysis Agent** | Computes TAM, SAM, SOM, compound annual growth rate (CAGR), and detailed multi-persona profiles. |
| **4** | **Competitor Discovery Agent** | Identifies direct, indirect, and substitute players, constructs feature matrices, and discovers white spaces. |
| **5** | **SWOT & Risk Agent** | Compiles 4-quadrant SWOT and categorized risk register (execution, AI, regulatory, financial) with severity scoring. |
| **6** | **MVP Feature Agent** | Prioritizes feature roadmap using the MoSCoW framework across 3 sprint phases with lean tech stack advice. |
| **7** | **GTM Strategy Agent** | Formulates ICP, positioning statements, top acquisition channels, first 100 customers playbook, and unit economics. |
| **8** | **Report Generation Agent** | Synthesizes an executive verdict (e.g. `STRONG GO WITH FOCUS`), composite score, and exports PDF, Markdown, and JSON. |
| **9** | **Conversational Advisor** | Interactive multi-turn AI consultant allowing founders to stress-test their validated venture in real time. |

## ⚡ Tech Stack & Architecture

- **Frontend / Dashboard**: Streamlit (v1.52) with custom dark-mode glassmorphic CSS, micro-animations, Plotly metric gauges, and responsive cards.
- **LLM Reasoning Layer**: Unified client supporting:
  - **Groq** (`llama-3.3-70b-versatile`, `mixtral-8x7b-32768`)
  - **Google Gemini** (`gemini-1.5-flash`, `gemini-2.0-flash`)
  - **OpenAI** (`gpt-4o-mini`, `gpt-4o`)
  - **Ventura Heuristic Engine**: Domain-aware offline reasoning fallback ensuring zero disruption when API keys are absent.
- **Search Retrieval Layer**: Tavily API with automatic live `ddgs` (DuckDuckGo Search) fallback.
- **Report Generation**: ReportLab PDF engine with custom typography, clean grids, two-pass dynamic page numbering, and executive styling.
- **Data Validation**: Pydantic v2 schemas enforcing strict typing across all agent context boundaries.

## 🚀 Quickstart Guide

### 1. Installation
Clone the repository and install dependencies:
```bash
cd "c:\Users\pmrsa\OneDrive\Desktop\7"
pip install -r requirements.txt
```

### 2. Configure Environment (Optional)
Create a `.env` file in the project root:
```env
# Optional: Set API keys or enter them directly in the UI sidebar
TAVILY_API_KEY=your_tavily_key
GROQ_API_KEY=your_groq_key
GEMINI_API_KEY=your_gemini_key
OPENAI_API_KEY=your_openai_key
```
> *Note: If no keys are provided, Ventura AI automatically uses live web search fallback and the built-in intelligent heuristic reasoning engine.*

### 3. Run the Web Application
```bash
python -m streamlit run app.py
```
Open your browser to `http://localhost:8501`.
